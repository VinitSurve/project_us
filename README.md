## 📖 Overview

**PROJECT: US** is an interactive, mobile-first, presentation-style web application designed as a formal confidential corporate business proposal—hijacked by feline consultants, inside jokes, memories from Hacknova, and sincere affection.

Built with React 19, TypeScript, Vite, Framer Motion, and synthesized Web Audio sound effects.

---

## 🏛️ The 8 Acts

1. **ACT I — The Cat Portal**: Diagnostic boot sequence, summons portal, classified dossier cover, and Feline Non-Disclosure Agreement.
2. **ACT II — The Business Proposal**: Executive summary, problem statement, 4-step pilot date roadmap, mission & vision, and core covenants.
3. **ACT III — The Archives Department**: Hacknova origin story with inspectable git log, interactive timeline, framed photo museum, and inside jokes.
4. **ACT IV — The Compatibility Laboratory**: Peer-reviewed metrics, dramatic 34/36 Guna Ashtakoota reveal with cosmic siren, and red-team reality check.
5. **ACT V — Meet The Candidates**: Candidate A (The Developer) & Candidate B (**बाळ**), with the proposed duo synergy equation.
6. **ACT VI — The Partnership Plan**: Value propositions, interactive bucket list bookmarks, relationship standard operating procedures, and risk register.
7. **ACT VII — Feline Brainrot Hub**: Interactive kitten petting lab with live 0–100% Purr Meter, floating emojis, meme quote generator, and persistent desktop companion Billi-Bot.
8. **ACT VIII — The Final Decision**: Intimate founder's note, the central sincere question, 4 dignified ballot options with celebratory confetti, executive credits, and quiet midnight epilogue.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Vanilla CSS tokens & modular design system
- **Motion**: Framer Motion
- **Audio**: Pure Web Audio API Synthesizer (Zero external audio dependencies)
- **Icons**: Lucide React
- **Confetti**: Canvas-Confetti
