# PROJECT: US — Cat Meme Starter Pack

This ZIP is a scene-organized starter pack for the romantic cat-meme presentation.

## Folders
- 01_intro_chaos — funny/chaotic opening
- 02_our_lore — inside jokes and shared story
- 03_funny_reactions — playful reaction beats
- 04_cute_wholesome — cute, warm moments
- 05_soft_romance — gentle romantic transition
- 06_heartfelt_finale — sincere ending

Each folder contains an original, editable SVG cat-meme-style card and a short README.
These are custom starter visuals, not downloaded Hugging Face dataset images.

## Hugging Face source for Ant
Dataset: https://huggingface.co/datasets/pielet/cat-memes

Please verify dataset metadata, licenses, and attribution requirements before publishing.
Use the dataset as an optional meme asset source, organize selected files by scene mood,
and keep the asset references easy to replace with user-provided memes and personal photos.
